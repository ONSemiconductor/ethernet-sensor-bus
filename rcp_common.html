Common Definitions

File: rcp_common.proto

Package: esb

Definitions that several files of the RCP protocol share.

This file holds the few definitions that other files share: endpoint types and queries, notification ownership, the timestamp, and the version.

Endpoints

The type of an endpoint tells which messages describe it: GPIO Driver, UART Driver, SPI Driver, I2C Driver, ADC Driver, PWM Driver, PDM Driver, PCM Audio Driver, LIN Driver, or SENT Driver. The server lists its endpoints with their handles and types in the result of the query rcp.dev.qryInterfaces (see Identification and Capabilities).

Timestamps and versions

Time is expressed in the format of the Precision Time Protocol (PTP, IEEE 802.1AS), see PTP. Besides absolute times of the PTP timer, the protocol also uses it for time spans, such as the offset, the period, and the delays of an action.

The server reports the version of the RCP protocol that it implements in its identity (see Identification and Capabilities).
