Protocol

Messages

fldDescriptors

Message esb.rcp.pins.fldDescriptors

RCP server pin descriptors.

Fields

  • dsc — repeated fldDescriptor
    List of pin descriptors.

fldDescriptors.fldDescriptor

Message esb.rcp.pins.fldDescriptors.fldDescriptor

Single instance of a pin descriptor.

Fields

  • num — uint32
    Unique pin identifier within the controller.

  • caps — uint32
    Pin capabilities. caps is a bit mask, according to the enCapability enum.

  • fun — repeated fldFunction
    List of endpoints/functions the pin can be associated with. If not present (empty), all handles and functions are supported. On a server with a static mapping, the list holds the one endpoint and function that the pin is fixed to.

fldDescriptors.fldDescriptor.fldFunction

Message esb.rcp.pins.fldDescriptors.fldDescriptor.fldFunction

Fields

  • hndl — uint32
    Handle of the endpoint.

  • sub — oneof

    • uart — enPinFuncUart
      UART/LIN subfunction.

    • spi — enPinFuncSpi
      SPI/ADC subfunction.

    • i2c — enPinFuncI2c
      I2C subfunction.

    • pcm — enPinFuncPcm
      PCM subfunction.

    • pdm — enPinFuncPdm
      PDM subfunction.

fldConfig

Message esb.rcp.pins.fldConfig

Container for the pin configuration message.

Fields

  • pin — repeated fldConfigItem
    List of pin configurations.

fldConfig.fldConfigItem

Message esb.rcp.pins.fldConfig.fldConfigItem

Single instance of a pin configuration.

Fields

  • num — uint32
    Unique pin identifier within the RCP server, as reported by dev.qryPins.

  • hndl — optional uint32
    If set, associates the pin with a specific endpoint instance. The exact pin function within the specified endpoint (e.g., SPI MISO or SPI MOSI) can be fixed based on the specified endpoint handle, or it can be further specified using the fun parameter (within this message), if supported by the server hardware. If the pin cannot be associated with the specified endpoint instance, the configuration operation fails with the cfgNotSupported error code.

  • pullMode — optional enPull
    If set, enables or disables the pin’s pull-up/down resistor when the endpoint supports it and the pin is in push-pull mode. If the pin does not support the specified pullMode, the configuration operation fails with the cfgNotSupported error code.

  • driverMode — optional enDriver
    If set, changes the pin driver configuration. If the pin does not support the specified driverMode, the configuration operation fails with the cfgNotSupported error code.

  • padStrength — optional uint32
    If set, defines the pad strength in microamperes (uA). The specific server may round this parameter to the nearest supported value. To retrieve the actual value set by the HW, the client can use the dev.qryPinConfig query.

  • fun — oneof
    If set, defines the pin function within the endpoint specified by the hndl field. If a server implementation does not support the explicit selection of the pin function (i.e., the endpoint’s pin locations are fixed) and this field is set, the configuration fails with the cfgNotSupported error code.

    • uart — enPinFuncUart
      UART/LIN pin functions.

    • spi — enPinFuncSpi
      SPI/ADC pin functions.

    • i2c — enPinFuncI2c
      I2C pin functions.

    • pcm — enPinFuncPcm
      PCM pin functions.

    • pdm — enPinFuncPdm
      PDM pin functions.

    • gpio — uint32
      GPIO pin index (0-based index within the controller).

Enumerations

enCapability

Enumeration esb.rcp.pins.enCapability

Capabilities of a pin, used as bit mask values.

  • capNone — No capabilities.

  • capInput — Pin can be configured as input.

  • capOutput — Pin can be configured as output.

  • capDrvPushPull — Pin supports push-pull driver mode.

  • capDrvOpenDrain — Pin supports open-drain driver mode (cannot drive strong ‘1’).

  • capDrvOpenSource — Pin supports open-source driver mode (cannot drive strong ‘0’).

  • capTristate — Pin supports tristate mode.

  • capRpu — Pin has a weak pull-up resistor.

  • capRpd — Pin has a weak pull-down resistor.

  • capIrq — Pin can be used as an IRQ source for notifications.

enPinFuncUart

Enumeration esb.rcp.pins.enPinFuncUart

Pin functions for the UART and LIN endpoints.

  • pinUartTx — Transmit Data.

  • pinUartRx — Receive Data.

  • pinUartRts — Ready To Send.

  • pinUartCts — Clear To Send.

enPinFuncSpi

Enumeration esb.rcp.pins.enPinFuncSpi

Pin functions for the SPI and the ADC endpoints.

  • pinSpiSclk — Serial Clock.

  • pinSpiMosi — Master Out Slave In.

  • pinSpiMiso — Master In Slave Out.

  • pinSpiCs — Chip-Select.

enPinFuncI2c

Enumeration esb.rcp.pins.enPinFuncI2c

Pin functions for the I2C endpoint.

  • pinI2cScl — Serial Clock.

  • pinI2cSda — Bidirectional serial data.

enPinFuncPcm

Enumeration esb.rcp.pins.enPinFuncPcm

Pin functions for the PCM audio endpoint.

  • pinPcmSck — Serial Clock.

  • pinPcmSd — Serial Data.

  • pinPcmWs — Word-Select / LR / Frame.

enPinFuncPdm

Enumeration esb.rcp.pins.enPinFuncPdm

Pin functions for the PDM endpoint.

  • pinPdmDin — Data In.

  • pinPdmClk — Clock Out.

enPull

Enumeration esb.rcp.pins.enPull

Pin pull-up/down mode.

  • pullNone — Disable pull-up/down.

  • pullUp — Enable pull-up resistor.

  • pullDw — Enable pull-down resistor.

enDriver

Enumeration esb.rcp.pins.enDriver

GPIO/PWM pin driver mode.

  • drvPushPull — Push-pull: actively drives both ‘0’ and ‘1’.

  • drvOpenDrain — Open-drain: actively drives ‘0’ only (cannot drive strong ‘1’).

  • drvOpenSource — Open-source: actively drives ‘1’ only (cannot drive strong ‘0’).
