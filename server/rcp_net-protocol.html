fldStatus

Message esb.rcp.net.fldStatus

Network status records.

Fields

  • phyMode — enPhyMode
    Current mode the embedded PHY is operating in.

  • lnkMode — enLinkMode
    Current Ethernet link mode.

  • lnkSpeed — enLinkSpeed
    Current Ethernet link speed.

  • ipAddr — optional fixed32
    Current IPv4 address.

  • sqi — optional uint32
    Current value of SQI+.

  • subnetPrefixLength — optional uint32
    Current subnet prefix length.

fldConfig

Message esb.rcp.net.fldConfig

Network configuration container.

Fields

  • macAddr — optional bytes
    Configured MAC address. If set, the RCP server uses the specified MAC address for communications. When the MAC address changes, the RCP server sends the reply to the configuration operation with the old MAC address as source address. If not configured (default), the RCP server uses the factory-default MAC address, if available. Otherwise, it uses a fixed or randomly generated MAC address.

  • ipAddr — optional fixed32
    If set, changes the current IPv4 address of the RCP server. When the IPv4 address changes, the RCP server sends the reply to the configuration operation with the old IP address as source address. If ipAddr is 0.0.0.0, the RCP server acquires an IPv4 address with DHCP or BOOTP. If it is 255.255.255.255, IPv4 is disabled. When IPv4 is enabled, the RCP server answers directives that arrive on the UDP port 7771 (0x1E5B) and uses the source port of the client as the destination port.

    Warning

    Setting the IP address to 127.x.x.x fails with the cfgInvalidParam code.

  • subnetPrefixLength — optional uint32
    Configures the subnetwork prefix length, which determines the subnet mask. This also affects the subnet broadcast address. For an example, see the page Network Configuration.

  • multicastAddrs — repeated fldMulticastItem
    List of the multicast addresses that the RCP server accepts.

  • vlanIds — repeated uint32
    If set, specifies a list of VLANs that the RCP server accepts. If this list is empty, the RCP server accepts only untagged frames, and silently drops all VLAN-tagged ones. The RCP server tracks the VLAN ID for the purpose of replying to clients:

    • Clients with the same MAC/IP address and different VLAN ID are considered different clients.

    • Replies preserve the original VLAN used by the client to communicate with the RCP server.

    Unsolicited RCP notifications use the VLAN that the client used for subscribing to the specific notification / endpoint.

  • defaultVlanId — optional uint32
    The VLAN ID to be used for unsolicited non-RCP protocol frames, for example ARP announcements or DHCP. If set to 0 (default), non-RCP protocols use untagged frames.

  • gratuitousArpEnable — optional bool
    If set to true, the server sends an ARP announcement after a successful IP address change. If set to false (default), the server does not announce its IP address on boot, regardless of the DHCP or static IP settings.

fldClientConfigItem

Message esb.rcp.net.fldClientConfigItem

Address of a client that the RCP server registers in advance. If the client has an IPv4 address, the RCP server identifies it by this address, its UDP port, and its VLAN ID, and sends its messages to it in UDP datagrams. Otherwise, the RCP server identifies the client by its MAC address and its VLAN ID, and sends its messages to it in raw Ethernet frames.

Fields

  • macAddr — bytes
    MAC address of the client. The RCP server uses it as the destination address of the Ethernet frames that carry its messages to the client.

  • vlanId — uint32
    VLAN ID of the client. If 0 (default), the client does not use a VLAN, and the RCP server sends its messages to it in untagged frames. Otherwise, it sends them in frames that carry this VLAN ID in their tag.

  • ipAddr — optional fixed32
    IPv4 address of the client. If set to a non-zero address, the RCP server sends its messages to the client in UDP datagrams to this address and to the port.

  • port — optional uint32
    UDP port of the client, to which the RCP server sends its UDP datagrams. It is only used if ipAddr is set.

fldClientConfig

Message esb.rcp.net.fldClientConfig

Registers clients in advance, i.e., before they send their first message. The RCP server learns a client from the messages that it receives from it. A registered client is known to the RCP server before it sends a message, so the RCP server can send messages to it without having received one from it first, e.g., the results of a stored action that it loads on boot. The client configuration is part of the server configuration. If it is saved (see rcp.dev.opSaveConfig), the RCP server knows the clients again after a restart, with the same client IDs, so that the stored actions that it loads still report to their clients.

Fields

  • clients — repeated fldClientConfigItem
    Clients to register. For each entry, the RCP server adds the client and assigns a client ID to it. If the RCP server already knows the client, it keeps the client ID. The query rcp.dev.qryClientStatus returns the client IDs.

fldClientStatusItem

Message esb.rcp.net.fldClientStatusItem

A client that the RCP server knows, with the client ID that the RCP server assigned to it. The address fields have the same meaning as those of fldClientConfigItem.

Fields

  • clientId — uint32
    Client ID that the RCP server assigned to the client. It is unique among the clients that the RCP server knows. The ID identifies the notification owner of an endpoint (fldEndpointNotifInfo.clientId) or the client that scheduled an action (rcp.core.fldSchedulerStatus.fldSchedulerItem.clientId).

  • macAddr — bytes
    MAC address of the client, 6 bytes.

  • vlanId — optional uint32
    VLAN ID of the client. Not set if the client does not use a VLAN.

  • ipAddr — optional fixed32
    IPv4 address of the client. Not set if the client does not have an IPv4 address.

  • port — optional uint32
    UDP port of the client. Set together with ipAddr.

fldClientStatus

Message esb.rcp.net.fldClientStatus

Status of the clients of the RCP server, returned by the query rcp.dev.qryClientStatus.

Fields

  • clients — repeated fldClientStatusItem
    The clients that the RCP server knows: the ones that it learned from their messages, and the ones that were registered with fldClientConfig.

fldMdioConfig

Message esb.rcp.net.fldMdioConfig

MDIO access container.

Fields

  • phyAddr — uint32
    PHY MDIO address.

  • mmd — optional uint32
    MMD address (0 = Clause 22).

  • regAddress — uint32
    Register address.

  • data — optional uint32
    Register data for write operations.

fldPhyReg

Message esb.rcp.net.fldPhyReg

Container for a list of MDIO register accesses.

Fields

  • mdioList — repeated fldMdioConfig
    List of MDIO accesses.

  • key — optional uint32
    Key that gives access to vendor-specific capabilities of the PHY. The meaning of the key and of the accesses that it enables is implementation-specific (refer to the datasheet of the server).

fldPhyData

Message esb.rcp.net.fldPhyData

Container for MDIO register read data.

Fields

  • data — repeated uint32
    List of MDIO register data for read operations.

Enumerations

enPhyMode

Enumeration esb.rcp.net.enPhyMode

Embedded Ethernet PHY modes.

  • phyUnknown — Unknown or no PHY.

  • phy10BASE_T1S — 10BASE-T1S PHY.

  • phy100BASE_T1 — 100BASE-T1 PHY.

enLinkMode

Enumeration esb.rcp.net.enLinkMode

Ethernet link modes.

  • lnkModeUnknown — Unknown or no link mode.

  • lnkModeHalfDuplex — Half duplex link.

enLinkSpeed

Enumeration esb.rcp.net.enLinkSpeed

Embedded Ethernet link speeds.

  • lnkSpeedUnknown — Unknown or no link speed.

  • lnkSpeed10M — 10 Mbps supported.

  • lnkSpeed100M — 100 Mbps supported.
