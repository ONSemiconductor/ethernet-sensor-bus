Messages

fldIdentity

Message esb.rcp.info.fldIdentity

RCP server identity records.

Fields

  • rcpVersion — fldVersion
    The current RCP protocol version implemented by the RCP server.

  • macAddr — bytes
    The factory-default MAC address of the server.

    Warning

    This can differ from the actual MAC address the RCP server is using if the client configured a new MAC address using net.fldConfig.

    Note

    Some vendor implementations do not provide a default (globally-unique) MAC address permanently stored in the RCP server.

  • vendor — optional string
    Optional UTF-8 string containing the RCP server vendor name.

  • pid — optional uint32
    Optional product identifier (managed by the vendor).

  • version — optional uint32
    Optional product version identifier (managed by the vendor).

  • serial — optional string
    Optional product serial number/string (managed by the vendor).

  • date — optional uint32
    Optional manufacturing date in UNIX format (seconds since 1st Jan 1970 00:00:00).

  • sid — optional uint32
    Optional system-level unique identifier (not to be confused with the DID).

fldCapabilities

Message esb.rcp.info.fldCapabilities

RCP server capability records.

Fields

  • supportedPhyModes — repeated net.enPhyMode
    List of communication standards supported by the PHY.

  • plcaSupported — bool
    If set, indicates the RCP server supports Physical Layer Collision Avoidance (PLCA) for the PHY modes that support it (e.g., 10BASE-T1S).

  • topologyDiscoverySupported — bool
    If set, the RCP server supports the Topology Discovery feature for the PHY modes that support it (e.g., 10BASE-T1S).

  • sqiSupported — bool
    If set, the RCP server supports the SQI feature for the PHY modes that support it (e.g., 100BASE-T1 and 10BASE-T1S).

  • wakeSleepSupported — bool
    If set, the RCP server supports the OPEN Alliance TC10 wake/sleep feature for the PHY modes that support it (e.g., 100BASE-T1 and 10BASE-T1S).

fldInterfaces

Message esb.rcp.info.fldInterfaces

RCP interface descriptors.

Fields

  • dsc — repeated fldInterfaceDescriptor
    List of endpoint descriptors. Each interface has a type and a unique ID (handle) that can be used for configuration and actions.

fldInterfaces.fldInterfaceDescriptor

Message esb.rcp.info.fldInterfaces.fldInterfaceDescriptor

Single instance of an endpoint descriptor.

Fields

  • hndl — uint32
    The unique endpoint identifier (handle).

    Note

    This number cannot be 0 as it is reserved for the RCP server itself.

  • type — enEndpointType
    Endpoint type (SPI, I2C, …)
