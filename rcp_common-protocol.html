Messages

fldEndpointNotifInfo

Message esb.fldEndpointNotifInfo

Notification ownership and sequence state of an endpoint. An endpoint has at most one notification owner and sends its notifications only to that client.

Fields

  • used — bool
    True if the endpoint has a notification owner.

  • clientId — uint32
    Client ID of that owner, valid if used is true.

  • seq — uint32
    Last notification sequence number, valid if used is true.

fldTstamp

Message esb.fldTstamp

Time expressed in seconds and nanoseconds. The containing field selects an absolute PTP time or a non-negative time span, e.g., an action period or delay. The seconds component is 32 bits.

Fields

  • sec — fixed32
    Seconds component.

  • nsec — fixed32
    Nanoseconds component.

fldVersion

Message esb.fldVersion

Version record.

Fields

  • major — uint32
    The major version number.

  • minor — uint32
    The minor version number.

  • patch — uint32
    The patch number.

Enumerations

enEndpointType

Enumeration esb.enEndpointType

Endpoint types handled by the RCP protocol.

  • devTypeGpio — General Purpose I/O Interface (GPIO).

  • devTypeUart — Universal Asynchronous Receiver-Transmitter (UART) Interface.

  • devTypeSpi — Serial Peripheral Interface (SPI).

  • devTypeI2c — Inter-Integrated Circuit (I2C) Interface.

  • devTypeAdc — Analog-to-Digital Converter (ADC) Interface.

  • devTypePwm — Pulse-Width Modulation (PWM) Interface.

  • devTypePdm — Pulse-Density Modulation (PDM) Interface.

  • devTypePcm — Pulse-Code Modulation (PCM) Audio Interface.

  • devTypeLin — Local Interconnect Network (LIN) Interface.

  • devTypeSent — Single Edge Nibble Transmission (SENT) Interface.

enEndpointQuery

Enumeration esb.enEndpointQuery

Types of query that an endpoint answers.

  • epqConfig — Get current endpoint configuration.

  • epqNotifInfo — Get notification ownership and sequence state.
