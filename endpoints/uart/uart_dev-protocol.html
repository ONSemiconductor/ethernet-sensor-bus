Messages

fldConfig

Message esb.uart.fldConfig

Message sent by the client to configure the UART. The line parameters speedBps, numDataBits, numStopBits, and parityBit apply to both the receiver and the transmitter. The parameters with the prefix tx affect only the transmitter, and those with the prefix rx affect only the receiver. The flow control parameters are swFlowControl, hwFlowControl, and hwFlowControlPolInv.

Fields

  • speedBps — optional uint32
    The bit rate in bits per second (bps). If the requested speed is fully supported by the RCP server, the configuration is accepted with the cfgSuccess return code. The RCP server is allowed to round the requested speed to the nearest supported speed within a reasonable tolerance (refer to the datasheet of the server). In this case, the configuration is accepted with the cfgParamAdjusted warning code and the client can retrieve the actual (rounded) speed by querying the configuration of the endpoint.

  • numDataBits — optional uint32
    The number of data bits per word (e.g., 8 in 8N1).

  • numStopBits — optional uint32
    The number of stop bits (e.g., 1 in 8N1).

  • parityBit — optional enParityBit
    The type of the parity bit (e.g., N for none in 8N1).

  • txPolInv — optional bool
    When false, the TX pin is active low. When true, the TX pin is active high.

  • rxPolInv — optional bool
    When false, the RX pin is active low. When true, the RX pin is active high.

  • txDelayUs — optional uint32
    The minimum pause in microseconds between two chunks of a block (see fldCmd.chunkSize).

  • swFlowControl — optional bool
    If true, enables software flow control (XON/XOFF).

  • hwFlowControl — optional bool
    If true, enables hardware flow control (RTS/CTS).

  • hwFlowControlPolInv — optional bool
    If true, inverts the polarity of the hardware flow control signals (RTS/CTS).

  • txBreakBitTime — optional uint32
    The duration of a transmitted break in bit times.

  • rxEnable — optional bool
    Enables the UART receiver. Received-data notifications are sent only when it is enabled.

  • rxLength — optional uint32
    The number of received words that triggers a notification (length-triggered mode). 0 selects the size of the UART buffer. The configuration fails with the cfgInvalidParam error code if the length exceeds the size of the UART buffer.

  • rxTimeoutEnable — optional bool
    Enables the time-triggered mode.

  • rxTimeoutBitTime — optional uint32
    The timeout of the time-triggered mode in bit times.

  • rxTerminalByteEnable — optional bool
    Enables the terminator-triggered mode.

  • rxTerminalByte — optional uint32
    The terminal byte (e.g., 10 for the line feed '\n').

  • rxStartByteEnable — optional bool
    Enables the start-byte-triggered mode. The mode also needs rxTerminalByteEnable.

  • rxStartByte — optional uint32
    The start byte (e.g., 36 for '$').

  • rxSuppressLoopback — optional bool
    If true, the UART discards one received word for each word it transmits, without checking whether the timing or the data content of the received word is identical. On half-duplex links, this prevents the transmitted data from being looped back to the client.

    Note

    Enabling this makes it impossible to detect transmission errors, e.g., due to collisions.

fldCmd

Message esb.uart.fldCmd

Message sent by the client to transmit data over the UART.

Fields

  • txData — bytes
    Bytes to send. At least 1 byte is required.

  • txBreak — bool
    If true, the UART sends a break before each chunk of data (see chunkSize). With the default chunkSize, it sends a single break.

  • chunkSize — uint32
    If non-zero, the UART sends the data in chunks of this size, with the pause fldConfig.txDelayUs between the chunks. If 0 (default), it sends the data in one chunk.

    Note

    The maximum chunk size depends on the server (refer to the datasheet of the server).

Enumerations

enParityBit

Enumeration esb.uart.enParityBit

Parity bit of a UART word.

  • parityNone — No parity bit.

  • parityEven — Even parity.

  • parityOdd — Odd parity.

  • parityMark — Mark parity: the parity bit is always 1.

  • paritySpace — Space parity: the parity bit is always 0.
