Protocol

Messages

fldInterfaceSerial

Message esb.adc.fldInterfaceSerial

The ESB protocol allows ADC endpoints to be internal or external to the RCP server. This interface allows configuration of an external ADC endpoint. The external ADC serial interface assumes the ADC has only three pins, similar to an SPI interface. In fact, the pin configuration message is the same as that of an SPI endpoint (see rcp.pins.enPinFuncSpi).

  • rcp.pins.pinSpiSclk: the clock from the RCP server to the external ADC

  • rcp.pins.pinSpiMiso: the ADC serial data output pin (input to RCP server)

  • rcp.pins.pinSpiCs: the chip-select, marking the start of the sampling period

The parameters dataBits, leftPaddingBits, rightPaddingBits, cpol, cpha and msbFirst define the length of a single acquisition. For an example, see the page ADC Driver.

The RCP server starts the conversion by asserting the chip select (CS). The leftPaddingBits defines how many clock cycles to wait before the first valid data bit appears at the ADC data pin. This allows time for the ADC to perform sample & hold, depending on the ADC type and performance. The dataBits parameter tells the RCP server how many data bits to sample. This should be set according to the ADC resolution. Finally, the rightPaddingBits parameter sets how many clock cycles to wait before de-asserting the chip-select. Some ADCs require these extra clock cycles to reset the internal state before a new conversion can happen. The total number of clock cycles for a single acquisition is therefore the sum of leftPaddingBits, dataBits, and rightPaddingBits. The cpol, cpha and msbFirst parameters are the same as those used for a normal SPI interface. See spi.fldConfig for more information.

Fields

  • speedHz — optional uint32
    The clock speed in hertz (Hz). If the requested speed is fully supported by the RCP server, the configuration is accepted with the cfgSuccess return code. The RCP server is allowed to round the requested speed to the nearest supported speed within a reasonable tolerance (refer to the datasheet of the server). In this case, the configuration is accepted with the cfgParamAdjusted warning code and the client can retrieve the actual (rounded) speed by querying the configuration of the endpoint.

  • dataBits — optional uint32
    Number of bits in each ADC sample.

  • leftPaddingBits — optional uint32
    Number of clock cycles before the first data bit.

  • rightPaddingBits — optional uint32
    Number of clock cycles after the last data bit.

  • cpol — optional bool
    Clock polarity (same as SPI CPOL).

  • cpha — optional bool
    Clock phase (same as SPI CPHA).

  • msbFirst — optional bool
    If true, ADC data is captured MSb first.

  • csDelay — optional uint32
    CS to SCLK delay in half clock periods. This parameter defines the additional delay between the chip select assertion and the first clock edge, as well as the delay between the last clock edge and the de-assertion of the chip-select. The total delay is calculated as (csDelay + 1) / (2 * speedHz) seconds.

fldThresholdConfig

Message esb.adc.fldThresholdConfig

Each ADC channel has configurable thresholds to generate internal events and notifications. The thresholds evaluate the value at the ADC filter output, that is, after all configured on-chip post-processing except decimation. When a threshold is enabled and triggered, it generates an internal event that can be used to fire pre-configured (re)actions for use cases requiring low latency. In addition to the internal event, a threshold can be configured to send a notification message when triggered.

Fields

  • value — optional uint32
    Unsigned threshold value, see enValueType.

  • event — optional enThresholdEvent
    Configures which threshold crossings generate an event.

  • notify — optional bool
    If set, sends a notification to the client when an event occurs.

fldChannelConfig

Message esb.adc.fldChannelConfig

Configuration for each ADC channel post-processor.

Fields

  • fltLP — optional uint32
    Filter factor for the ADC channel. This value determines the strength of the low-pass filter applied to the ADC samples. The filter transfer function is: OUT[i] = (IN[i] + fltLP * OUT[i - 1]) / (fltLP + 1 ) Setting fltLP to 0 (default) disables low-pass filtering (OUT[i] = IN[i]).

  • decimationFactor — optional uint32
    Decimation factor for the ADC channel. This value determines the number of samples reported to the client. The decimator reports 1 sample every \(2^N\) samples, where \(N\) is decimationFactor. Setting decimationFactor = 0 (default) disables decimation (all samples are reported to the client). Decimation affects streamed samples only. Thresholds evaluate the filtered samples before decimation, see fldThresholdConfig.

  • initialValue — optional uint32
    Initial value for the ADC channel filter output. This value is the initial output value of the ADC post-processing block when the ADC starts. This can be used to avoid glitches on the configured thresholds.

  • valueType — optional enValueType
    Configures the value type of the ADC samples for this channel.

  • threshold1 — optional fldThresholdConfig
    Threshold configuration for the first threshold event.

  • threshold2 — optional fldThresholdConfig
    Threshold configuration for the second threshold event.

  • channelId — optional uint32
    If the ADC device supports multiple channels, this parameter represents the channel number identifier, that is, the channel multiplexer (MUX) selector number. This identifier can be used to instruct the ADC to sample channels in a specific order / sequence.

fldConfig

Message esb.adc.fldConfig

ADC post-processing configuration.

Fields

  • sampleRateHz — optional uint32
    The ADC sample rate in hertz (Hz). This parameter configures the speed at which ADC samples are fed into the ADC post-processing block. If an external ADC interface is used, the time interval between two CS pin assertions is 1 / sampleRateHz. If the requested frequency is fully supported by the RCP server, the configuration is accepted with the cfgSuccess return code. The RCP server is allowed to round the requested frequency to the nearest supported speed within a reasonable tolerance (refer to the datasheet of the server). In this case, the configuration is accepted with the cfgParamAdjusted warning code and the client can retrieve the actual (rounded) speed by querying the configuration of the endpoint.

    Note

    On some implementations, the sample rate can be synchronous to the internal PTP clock.

    Warning

    Do not confuse the sample rate with the external ADC clock speed, which is configured with the fldInterfaceSerial message.

  • bufferSizeBytes — optional uint32
    This parameter sets the size in bytes of the internal ADC buffer. When the amount of sampled data exceeds bufferSizeBytes, the RCP server sends out a notification message including all the captured samples.

  • channels — repeated fldChannelConfig
    Configuration for each channel.

  • interface — oneof
    Defines the ADC physical interface. If none of the options is selected, the configuration targets the first available internal ADC.

    • serial — fldInterfaceSerial
      Configuration for the SPI ADC interface.

fldCmd

Message esb.adc.fldCmd

Container for ADC commands.

Fields

  • op — optional enCmdOperation
    ADC operation.

  • quiet — bool
    If set, suppresses data streaming to the client.

fldNotif

Message esb.adc.fldNotif

Container for ADC event notifications.

Fields

  • channelId — uint32
    ID of the channel that generated the event.

  • event — enNotifEvent
    Type of the event.

  • value — uint32
    Value that triggered the event.

Enumerations

enThresholdEvent

Enumeration esb.adc.enThresholdEvent

Threshold crossing that generates an event.

  • thresholdEvtNone — No trigger (disables the threshold).

  • thresholdEvtAbove — Trigger if the filtered output rises above fldThresholdConfig.value.

  • thresholdEvtBelow — Trigger if the output falls below fldThresholdConfig.value.

  • thresholdEvtCrossing — Trigger if the output crosses fldThresholdConfig.value in either direction.

enValueType

Enumeration esb.adc.enValueType

This enumeration defines the ADC data format as produced by the internal or external ADC endpoint. This setting affects the ADC post-processing and filtering arithmetic.

Note

The threshold value (fldThresholdConfig.value), the initial value (fldChannelConfig.initialValue) and the value in a notification (fldNotif.value) are unsigned integers, regardless of the selected format.

  • valueUnsigned — Standard n-bit unsigned sample data (10010101 = 149 dec.)

  • valueComplement — Signed two’s complement number (10010101 = -107 dec.)

  • valueSignBit — Sign bit plus integer part, i.e., the MSb is used as sign bit (10010101 = -21 dec.)

enCmdOperation

Enumeration esb.adc.enCmdOperation

ADC operation types.

  • opStart — Start the ADC in free-running mode.

  • opStop — Stop the ADC.

  • opSingle — Capture a single buffer, then stop.

enNotifEvent

Enumeration esb.adc.enNotifEvent

Type of ADC event.

  • eventThreshold1 — An event occurred on threshold 1.

  • eventThreshold2 — An event occurred on threshold 2.
