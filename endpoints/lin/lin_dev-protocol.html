Messages

fldConfig

Message esb.lin.fldConfig

LIN configuration message.

Fields

  • speedBps — optional uint32
    The bit rate in bits per second (bps). If the requested speed is fully supported by the RCP server, the configuration is accepted with the cfgSuccess return code. The RCP server is allowed to round the requested speed to the nearest supported speed within a reasonable tolerance (refer to the datasheet of the server). In this case, the configuration is accepted with the cfgParamAdjusted warning code and the client can retrieve the actual (rounded) speed by querying the configuration of the endpoint.

  • identifierParity — optional bool
    If set to true, the endpoint automatically calculates and appends the parity bits to the identifier. Otherwise, the fldCmd.frameId field includes the parity bits.

  • checksumType — optional enChecksumType
    LIN checksum type.

  • rxSuppressLoopback — optional bool
    If used with a LIN transceiver that loops back the transmitted data to the receiver, setting this to true suppresses the loopback.

  • txBreakBitTime — optional uint32
    The break condition duration in bit times.

fldCmd

Message esb.lin.fldCmd

Container for LIN command.

Fields

  • mode — oneof

    • wdata — bytes
      Bytes to send. If checksum is enabled, checksum byte(s) are appended automatically.

    • rsize — uint32
      Number of bytes to read. If checksum is enabled, checksum byte(s) are read and verified automatically.

  • frameId — uint32
    Identifier of the LIN frame. If fldConfig.identifierParity is false, it includes the parity bits.

  • checksumType — optional enChecksumType
    If set, overrides the checksum configuration for this command.

Enumerations

enChecksumType

Enumeration esb.lin.enChecksumType

Checksum type for LIN messages.

  • checksumNone — Checksum disabled. The client has to handle it.

  • checksumClassic — Classic checksum (without identifier).

  • checksumEnhanced — Enhanced checksum (with identifier).
