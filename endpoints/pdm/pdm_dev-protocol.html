Messages

fldConfig

Message esb.pdm.fldConfig

PDM configuration message.

Fields

  • bufferSizeBytes — optional uint32
    Length of the buffer in bytes. Setting this to 0 configures the default buffer length. Exceeding the buffer size supported by the server causes the configuration to fail.

  • samplingEdge — optional enSamplingEdge
    PDM sampling edge configuration.

  • speedHz — optional uint32
    The clock speed in hertz (Hz). If the requested speed is fully supported by the RCP server, the configuration is accepted with the cfgSuccess return code. The RCP server is allowed to round the requested speed to the nearest supported speed within a reasonable tolerance (refer to the datasheet of the server). In this case, the configuration is accepted with the cfgParamAdjusted warning code and the client can retrieve the actual (rounded) speed by querying the configuration of the endpoint.

fldCmd

Message esb.pdm.fldCmd

Container for PDM command.

Fields

  • op — optional enCmdOperation
    PDM operation.

Enumerations

enSamplingEdge

Enumeration esb.pdm.enSamplingEdge

PDM sampling edge configuration options.

  • samplingRising — PDM configured to sample DATA on the CLK rising edge.

  • samplingFalling — PDM configured to sample DATA on the CLK falling edge.

  • samplingBoth — PDM configured to sample DATA on both CLK edges, rising and falling.

enCmdOperation

Enumeration esb.pdm.enCmdOperation

PDM operation types.

  • opStart — Start PDM.

  • opStop — Stop PDM.
