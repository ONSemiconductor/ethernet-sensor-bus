Ethernet Sensor Bus (ESB)

The Ethernet Sensor Bus (ESB) is a protocol for controlling hardware endpoints, such as SPI, I2C, GPIO, and UART controllers, over Ethernet. The application software runs on a central processor, the client, and controls the remote RCP servers. The servers contain the endpoints and run no application software, so the application is developed, tested, and updated in one place.

The following pages introduce the protocol:

  • Overview: the motivation, the scope, the conventions, the terms, and the references.

  • Operating principle: the roles of the client and the RCP server, the path of a directive, and the endpoints.

  • Messages: the structure of directives and reports.

  • Network: how messages reach an RCP server over Ethernet and, optionally, UDP/IP.

  • Scheduler: how an RCP server runs actions at the right time, repeatedly, or on events.

  • Higher-level behavior: persistent storage and fail-safe operation.

  • Usage hints: recommendations for working with RCP servers.

  • Protobuf encoding: how Protocol Buffers turn a message into bytes.

  • Code generators: how to get the encoder and decoder for a programming language.

The remaining pages describe the protocol fields in detail:

  • RCP Messages: the top-level messages and the containers of the operations.

  • Common Definitions: the definitions that several files share.

  • Server: the messages for the RCP server itself.

  • Endpoints: one page for each type of endpoint.
