Messages

fldCmdXfer

Message esb.spi.fldCmdXfer

SPI transfer token, building block to perform I/O operations. Three transfer types are supported:

  • full-duplex: a number of bytes (wdata) is transferred via MOSI and the same number of bytes, sampled from MISO, is returned.

  • write-only: as full-duplex, but the data from MISO is discarded and no buffer is returned to the client.

  • read-only: no data is transferred on MOSI, which is set to the constant value wpad during the transfer. Instead, rsize bytes are sampled from MISO and returned to the client.

Fields

  • xft — enXferType
    Selects the transfer type (full-duplex, write-only, read-only).

  • wdata — bytes
    When xft is set to xferFullDuplex or xferWriteOnly, the size of the transfer is set by the length of wdata, which contains the data to be sent over the MOSI pin.

  • rsize — uint32
    When xft is set to xferReadOnly, rsize determines the transfer length in bytes. This amount of data is appended to the data of the action result (fldActionResult.data).

  • wpad — bool
    When xft is set to xferReadOnly, the MOSI pin is set according to the value of wpad (False = 0, True = 1) for the duration of the transfer.

fldConfig

Message esb.spi.fldConfig

SPI configuration message.

Fields

  • msbFirst — optional bool
    If set, configures whether the data is sent/received MSB or LSB first.

  • cpol — optional bool
    If set, configures the clock polarity.

  • cpha — optional bool
    If set, configures the clock/data phase.

  • cs — optional uint32
    If set, configures the default pin to be used as the chip-select. The number is the unique pin identifier as reported by rcp.dev.qryPins.

  • csDelay — optional uint32
    CS to SCLK delay in half clock periods. The same delay applies to both sides of the transfer. This is in addition to the minimum delay.

  • speedHz — optional uint32
    The clock speed in hertz (Hz). If the requested speed is fully supported by the RCP server, the configuration is accepted with the cfgSuccess return code. The RCP server is allowed to round the requested speed to the nearest supported speed within a reasonable tolerance (refer to the datasheet of the server). In this case, the configuration is accepted with the cfgParamAdjusted warning code and the client can retrieve the actual (rounded) speed by querying the configuration of the endpoint.

fldCmd

Message esb.spi.fldCmd

Container for SPI commands.

Fields

  • param — optional fldConfig
    If set, overrides the specified configuration fields for this command only.

  • xfer — repeated fldCmdXfer
    List of transfer tokens. The chip-select is asserted on the first transfer token, and it is de-asserted after all tokens have been processed.

  • csHold — bool
    Keep CS low after the transaction.

Enumerations

enXferType

Enumeration esb.spi.enXferType

SPI transfer type.

  • xferFullDuplex — Perform R/W concurrently.

  • xferWriteOnly — Just write, discard data from MISO.

  • xferReadOnly — Just read, set MOSI to the PAD value.
