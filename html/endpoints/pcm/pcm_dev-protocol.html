Messages

fldChannelMask

Message esb.pcm.fldChannelMask

Container for specifying which portion of the data stream to ignore.

Fields

  • idx — uint32
    Index of the channel, starting from 0.

  • padding — oneof

    • leftBits — uint32
      Number of ignored padding bits before the first data bit in each channel.

    • rightBits — uint32
      Number of ignored padding bits after the last data bit in each channel.

fldConfig

Message esb.pcm.fldConfig

PCM configuration message.

Fields

  • dir — optional enDir
    PCM direction.

  • fsMode — optional enFsMode
    PCM FS mode.

  • fsInv — optional bool
    FS output inverted if true.

  • clkInv — optional bool
    FS clk inverted if true.

  • fsAlign — optional bool
    If true, the leading edge of fs is aligned with the first data bit. If false, the trailing edge of fs is aligned with the first data bit.

  • msbFirst — optional bool
    If set, configures whether the data is sent/received MSB or LSB first.

  • rxBufferSizeBytes — optional uint32
    Length of the buffer in bytes. Setting this to 0 configures the default buffer length. Exceeding the buffer size supported by the server causes the configuration to fail.

  • sampleRateHz — optional uint32
    Sample rate in hertz (Hz).

  • numChannels — optional uint32
    Number of channels. In I2S mode, this configuration is ignored, as the number of channels is fixed. In TDM mode, this can be set to any number up to the maximum supported by the server.

  • bitsPerSample — optional uint32
    Number of bits per audio sample.

  • channelMask — repeated fldChannelMask
    Configuration for ignoring data in specific channels, to save bandwidth.

fldCmd

Message esb.pcm.fldCmd

Container for PCM command.

Fields

  • op — optional enCmdOperation
    Operation to perform.

  • txData — bytes
    Audio stream to transmit when in output mode.

Enumerations

enDir

Enumeration esb.pcm.enDir

PCM direction.

  • dirIn — PCM configured as input (RX).

  • dirOut — PCM configured as output (TX).

enFsMode

Enumeration esb.pcm.enFsMode

PCM frame sync mode.

  • fsModeI2s — I2S mode.

  • fsModeTdm — TDM mode.

enCmdOperation

Enumeration esb.pcm.enCmdOperation

PCM operation types.

  • opStart — Start PCM.

  • opStop — Stop PCM.
