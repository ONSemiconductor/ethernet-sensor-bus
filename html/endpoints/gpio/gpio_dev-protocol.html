Protocol

Messages

fldPinConfig

Message esb.gpio.fldPinConfig

Configuration message for GPIO pins.

Fields

  • num — uint32
    Index of the pin within the controller, starting from 0. It is the GPIO number of the pin, which is its bit position in the masks of fldCmd and fldNotif.

  • event — optional enChangeEvent
    Configures which changes of the pin generate an event. An event generates an unsolicited notification, unless quiet is set, and it can trigger actions, see fldActionEvent. If PTP is configured and enabled, the notification contains the value of the PTP timer at the time the pin changed its state.

  • quiet — optional bool
    If set, suppresses notification reports for this pin. The change event can still be used to trigger other actions.

  • debounceNs — optional uint32
    Debounce time in nanoseconds.

fldConfig

Message esb.gpio.fldConfig

GPIO configuration message.

Fields

  • pin — repeated fldPinConfig
    Configuration for each GPIO pin.

fldCmd

Message esb.gpio.fldCmd

Container for GPIO commands. Each field is a mask with one bit per GPIO. A set bit applies the operation of the field to the GPIO whose number equals the bit position, starting with bit 0 (LSb). For an example, see the page GPIO Driver.

Fields

  • out — uint32
    Mask of pins to (re)configure as output.

  • inp — uint32
    Mask of pins to (re)configure as input.

  • get — uint32
    Mask of pins to get state for.

  • set — uint32
    Mask of pins to set state for.

  • clr — uint32
    Mask of pins to clear state for.

  • tgl — uint32
    Mask of pins to toggle state for.

fldNotif

Message esb.gpio.fldNotif

GPIO change notification.

Fields

  • state — uint32
    Current state of all GPIO pins for this controller (endpoint). The LSb represents the status of GPIO #0 within this controller.

  • change — uint32
    Mask of pins that changed state. A bit set in the mask at position N (starting from LSb) indicates that the GPIO #N changed state since the last notification.

Enumerations

enChangeEvent

Enumeration esb.gpio.enChangeEvent

Pin change that generates an event.

  • changeEvtNone — No event (default).

  • changeEvtRising — Generate an event when the pin transitions from 0 to 1.

  • changeEvtFalling — Generate an event when the pin transitions from 1 to 0.

  • changeEvtToggle — Generate an event any time the pin changes state.
