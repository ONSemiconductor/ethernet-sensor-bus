# PLCA

**File:** `server/rcp_plca.proto`

**Package:** `esb.rcp.plca`

Physical layer collision avoidance (PLCA) configuration and status of the RCP server.

10BASE-T1S is a multidrop network: all nodes share the same wire pair. PLCA lets them take turns instead of detecting
collisions. The RCP server supports it if [`rcp.info.fldCapabilities.plcaSupported`](#protogen.esb.rcp.info.fldCapabilities.plcaSupported) is set (see [Identification and Capabilities](#protogen.rcp_info)). The
configuration is part of the server configuration ([`rcp.dev.fldConfig.plca`](#protogen.esb.rcp.dev.fldConfig.plca)).

## PLCA cycle

One node of the network is the coordinator. It has the node ID 0, and every other node has a unique node ID. The
coordinator starts each PLCA cycle with a beacon. After the beacon, every node gets one transmit opportunity (TO) in
the order of the node IDs, and may send a frame in it. A node that has nothing to send lets its opportunity pass.
The opportunity then lasts a configurable number of bit times, the TO timer, before the next one starts. The cycle
ends after the opportunity of the last node, and the coordinator sends the next beacon.

![](../../../../sw_proto_rcp/figures/server/timingPlcaCycle.svg)

The time of a cycle depends on the number of nodes, their frames, and the TO timer for the unused
opportunities. If bursts are enabled, a node can send more than one frame in its opportunity.
