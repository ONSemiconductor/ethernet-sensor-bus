# Protocol

## Messages

(protogen.esb.fldEndpointNotifInfo)=

### fldEndpointNotifInfo

*Message* `esb.fldEndpointNotifInfo`

Notification ownership and sequence state of an endpoint.
An endpoint has at most one notification owner and sends its notifications only to that client.

**Fields**

- (protogen.esb.fldEndpointNotifInfo.used)=

  **`used`** — `bool`\
  True if the endpoint has a notification owner.

- (protogen.esb.fldEndpointNotifInfo.clientId)=

  **`clientId`** — `uint32`\
  Client ID of that owner, valid if [`used`](#protogen.esb.fldEndpointNotifInfo.used) is true.

- (protogen.esb.fldEndpointNotifInfo.seq)=

  **`seq`** — `uint32`\
  Last notification sequence number, valid if [`used`](#protogen.esb.fldEndpointNotifInfo.used) is true.

(protogen.esb.fldTstamp)=

### fldTstamp

*Message* `esb.fldTstamp`

Time expressed in seconds and nanoseconds. The containing field selects an absolute PTP time or a non-negative
time span, e.g., an action period or delay. The seconds component is 32 bits.

**Fields**

- (protogen.esb.fldTstamp.sec)=

  **`sec`** — `fixed32`\
  Seconds component.

- (protogen.esb.fldTstamp.nsec)=

  **`nsec`** — `fixed32`\
  Nanoseconds component.
