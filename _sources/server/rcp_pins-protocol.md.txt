### fldDescriptors.fldDescriptor

*Message* `esb.rcp.pins.fldDescriptors.fldDescriptor`

Single instance of a pin descriptor.

**Fields**

- (protogen.esb.rcp.pins.fldDescriptors.fldDescriptor.num)=

  **`num`** — `uint32`\
  Unique pin identifier within the controller.

- (protogen.esb.rcp.pins.fldDescriptors.fldDescriptor.caps)=

  **`caps`** — `uint32`\
  Pin capabilities.
  [`caps`](#protogen.esb.rcp.pins.fldDescriptors.fldDescriptor.caps) is a bit mask, according to the [`enCapability`](#protogen.esb.rcp.pins.enCapability) enum.

- (protogen.esb.rcp.pins.fldDescriptors.fldDescriptor.fun)=

  **`fun`** — *repeated* [`fldFunction`](#protogen.esb.rcp.pins.fldDescriptors.fldDescriptor.fldFunction)\
  List of endpoints/functions the pin can be associated with.
  If not present (empty), all handles and functions are supported.
  On a server with a static mapping, the list holds the one endpoint and function that the pin is fixed to.

### fldConfig.fldConfigItem

*Message* `esb.rcp.pins.fldConfig.fldConfigItem`

Single instance of a pin configuration.

**Fields**

- (protogen.esb.rcp.pins.fldConfig.fldConfigItem.num)=

  **`num`** — `uint32`\
  Unique pin identifier within the RCP server, as reported by [`dev.qryPins`](#protogen.esb.rcp.dev.enQuery.qryPins).

- (protogen.esb.rcp.pins.fldConfig.fldConfigItem.hndl)=

  **`hndl`** — *optional* `uint32`\
  If set, associates the pin with a specific endpoint instance.
  The exact pin function within the specified endpoint (e.g., SPI MISO
  or SPI MOSI) can be fixed based on the specified endpoint handle, or
  it can be further specified using the [`fun`](#protogen.esb.rcp.pins.fldConfig.fldConfigItem.fun) parameter (within this
  message), if supported by the server hardware.
  If the pin cannot be associated with the specified endpoint instance,
  the configuration operation fails with the [`cfgNotSupported`](#protogen.esb.enConfigResult.cfgNotSupported) error code.

- (protogen.esb.rcp.pins.fldConfig.fldConfigItem.pullMode)=

  **`pullMode`** — *optional* [`enPull`](#protogen.esb.rcp.pins.enPull)\
  If set, enables or disables the pin's pull-up/down resistor when
  the endpoint supports it and the pin is in push-pull mode.
  If the pin does not support the specified [`pullMode`](#protogen.esb.rcp.pins.fldConfig.fldConfigItem.pullMode), the configuration
  operation fails with the [`cfgNotSupported`](#protogen.esb.enConfigResult.cfgNotSupported) error code.

- (protogen.esb.rcp.pins.fldConfig.fldConfigItem.driverMode)=

  **`driverMode`** — *optional* [`enDriver`](#protogen.esb.rcp.pins.enDriver)\
  If set, changes the pin driver configuration.
  If the pin does not support the specified [`driverMode`](#protogen.esb.rcp.pins.fldConfig.fldConfigItem.driverMode), the
  configuration operation fails with the [`cfgNotSupported`](#protogen.esb.enConfigResult.cfgNotSupported) error code.

- (protogen.esb.rcp.pins.fldConfig.fldConfigItem.padStrength)=

  **`padStrength`** — *optional* `uint32`\
  If set, defines the pad strength in microamperes (uA).
  The specific server may round this parameter to the nearest
  supported value.
  To retrieve the actual value set by the HW, the client can use the
  [`dev.qryPinConfig`](#protogen.esb.rcp.dev.enQuery.qryPinConfig) query.

- (protogen.esb.rcp.pins.fldConfig.fldConfigItem.fun)=

  **`fun`** — *oneof*\
  If set, defines the pin function within the endpoint specified by
  the [`hndl`](#protogen.esb.rcp.pins.fldConfig.fldConfigItem.hndl) field. If a server implementation does not support the
  explicit selection of the pin function (i.e., the endpoint's
  pin locations are fixed) and this field is set, the configuration
  fails with the [`cfgNotSupported`](#protogen.esb.enConfigResult.cfgNotSupported) error code.

  - (protogen.esb.rcp.pins.fldConfig.fldConfigItem.uart)=

    **`uart`** — [`enPinFuncUart`](#protogen.esb.rcp.pins.enPinFuncUart)\
    UART/LIN pin functions.

  - (protogen.esb.rcp.pins.fldConfig.fldConfigItem.spi)=

    **`spi`** — [`enPinFuncSpi`](#protogen.esb.rcp.pins.enPinFuncSpi)\
    SPI/ADC pin functions.

  - (protogen.esb.rcp.pins.fldConfig.fldConfigItem.i2c)=

    **`i2c`** — [`enPinFuncI2c`](#protogen.esb.rcp.pins.enPinFuncI2c)\
    I2C pin functions.

  - (protogen.esb.rcp.pins.fldConfig.fldConfigItem.pcm)=

    **`pcm`** — [`enPinFuncPcm`](#protogen.esb.rcp.pins.enPinFuncPcm)\
    PCM pin functions.

  - (protogen.esb.rcp.pins.fldConfig.fldConfigItem.pdm)=

    **`pdm`** — [`enPinFuncPdm`](#protogen.esb.rcp.pins.enPinFuncPdm)\
    PDM pin functions.

  - (protogen.esb.rcp.pins.fldConfig.fldConfigItem.gpio)=

    **`gpio`** — `uint32`\
    GPIO pin index (0-based index within the controller).
