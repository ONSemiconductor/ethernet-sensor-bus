## Enumerations

(protogen.esb.rcp.dev.enCmdOperation)=

### enCmdOperation

*Enumeration* `esb.rcp.dev.enCmdOperation`

RCP server management operations.

- (protogen.esb.rcp.dev.enCmdOperation.opNone)=

  **`opNone`** — This operation is a no-op and does not alter the state of the RCP server.
  However, it counts as a network watchdog refresh message, so the
  client can use it as a keep-alive message.

- (protogen.esb.rcp.dev.enCmdOperation.opResetDevice)=

  **`opResetDevice`** — Reset the RCP server.
  If set, the RCP server reboots, clearing all dynamic configuration
  and resetting all internal states and variables.

- (protogen.esb.rcp.dev.enCmdOperation.opSaveConfig)=

  **`opSaveConfig`** — Saves the current RCP configuration into non-volatile memory.

- (protogen.esb.rcp.dev.enCmdOperation.opRestoreConfig)=

  **`opRestoreConfig`** — Restores the last saved RCP configuration from non-volatile memory.
  If the operation fails, the current configuration does not change.

- (protogen.esb.rcp.dev.enCmdOperation.opSleep)=

  **`opSleep`** — Commands the RCP server to enter deep-sleep mode.
  In deep-sleep mode, all RCP server functions are switched off, and all
  dynamic configuration and states are lost. A portion of the RCP server
  stays powered to detect wakeup signals from local sources or from the
  Ethernet bus. The wakeup signal triggers a full (re)boot of the server.

- (protogen.esb.rcp.dev.enCmdOperation.opRestoreFactoryConfig)=

  **`opRestoreFactoryConfig`** — Forces the RCP server to erase the NVM content and reboot.
  The default HW configuration is then applied when the system comes
  back to life.

- (protogen.esb.rcp.dev.enCmdOperation.opClearPwron)=

  **`opClearPwron`** — This command clears the [`core.fldServerStatus.pwrOn`](#protogen.esb.rcp.core.fldServerStatus.pwrOn) flag in the RCP server status.
  See [`core.fldServerStatus`](#protogen.esb.rcp.core.fldServerStatus) for more information.

- (protogen.esb.rcp.dev.enCmdOperation.opTopologyDiscovery)=

  **`opTopologyDiscovery`** — Commands the RCP server to initiate topology discovery if the HW
  supports it. 10BASE-T1S PHYs can provide this feature.

- (protogen.esb.rcp.dev.enCmdOperation.opManagePhyRegisters)=

  **`opManagePhyRegisters`** — Initiates an MDIO read or write operation to configure the PHY.
  See also [`net.fldMdioConfig`](#protogen.esb.rcp.net.fldMdioConfig).

- (protogen.esb.rcp.dev.enCmdOperation.opSetPtpTime)=

  **`opSetPtpTime`**\
  Sets the value for the internal PTP timer.
  Setting the PTP timer with this command can yield an error of several
  milliseconds, depending on the client latency and the network conditions.

  ```{warning}
  Setting the PTP timer with this method can make scheduled
  actions fail or be delayed for a long time, depending on the
  direction of the time shift.
  ```

- (protogen.esb.rcp.dev.enCmdOperation.opClearStoredActions)=

  **`opClearStoredActions`** — Clears all actions that are currently stored in the NVM.
  It does not affect actions loaded into volatile memory.

- (protogen.esb.rcp.dev.enCmdOperation.opEnterSilent)=

  **`opEnterSilent`**\
  Enter silent mode. Features such as 10BASE-T1S topology
  discovery or cable fault detection need the line to be silent.

  ```{note}
  The server sends back a confirmation once it has entered
  silent mode, unless suppressed explicitly.
  ```

- (protogen.esb.rcp.dev.enCmdOperation.opExitSilent)=

  **`opExitSilent`** — Leave silent mode.
  If the server was not in silent mode, this command is ignored.

- (protogen.esb.rcp.dev.enCmdOperation.opEnterFailsafe)=

  **`opEnterFailsafe`** — Forces the RCP server into fail-safe mode.

- (protogen.esb.rcp.dev.enCmdOperation.opCancelAllActions)=

  **`opCancelAllActions`** — Resets the RCP server scheduler, clearing all
  pending scheduled actions. This includes actions with a repetition count
  that still have pending executions.
  A running action always completes.

- (protogen.esb.rcp.dev.enCmdOperation.opGlobalWakeup)=

  **`opGlobalWakeup`**\
  Makes the PHY send a global wakeup signal on the Ethernet line to
  wake up all sleeping nodes on the same network segment.

  ```{note}
  Ethernet switches and PHYs can be programmed to propagate the wakeup
  signal further.
  ```

- (protogen.esb.rcp.dev.enCmdOperation.opLoadStoredActions)=

  **`opLoadStoredActions`**\
  Loads the stored actions from non-volatile memory.
  Existing actions loaded in RAM are not canceled.

  ```{warning}
  Executing this operation multiple times causes actions to
  be loaded multiple times into RAM.
  ```

- (protogen.esb.rcp.dev.enCmdOperation.opManageUserData)=

  **`opManageUserData`** — Access the user-dedicated NVM, i.e., write or read user data to/from
  non-volatile memory.
  See [`core.fldNvmOperation`](#protogen.esb.rcp.core.fldNvmOperation).

(protogen.esb.rcp.dev.enQuery)=

### enQuery

*Enumeration* `esb.rcp.dev.enQuery`

Queries of the RCP server.
Queries indicated with [M] are mandatory, meaning that ESB-compliant
servers implement them.
Queries marked with [H] are mandatory if the specific HW supports it.
Queries marked with [O] are optional to implement.

- (protogen.esb.rcp.dev.enQuery.qryServerConfig)=

  **`qryServerConfig`** — [M] Get current RCP server configuration.

- (protogen.esb.rcp.dev.enQuery.qryPtpConfig)=

  **`qryPtpConfig`** — [H] Get current PTP protocol configuration.

- (protogen.esb.rcp.dev.enQuery.qryPlcaConfig)=

  **`qryPlcaConfig`** — [H] Get current PLCA configuration.

- (protogen.esb.rcp.dev.enQuery.qryPinConfig)=

  **`qryPinConfig`** — [M] Get current RCP pins configuration.

- (protogen.esb.rcp.dev.enQuery.qryNetConfig)=

  **`qryNetConfig`** — [M] Get current network configuration.

- (protogen.esb.rcp.dev.enQuery.qryRegConfig)=

  **`qryRegConfig`** — [H] Get default register configuration.

- (protogen.esb.rcp.dev.enQuery.qryIdentity)=

  **`qryIdentity`** — [M] Get basic server information (vendor, serial, ...).

- (protogen.esb.rcp.dev.enQuery.qryCapabilities)=

  **`qryCapabilities`** — [O] Get server capabilities (supported features).

- (protogen.esb.rcp.dev.enQuery.qryInterfaces)=

  **`qryInterfaces`** — [O] Retrieve a list of supported endpoints (SPI, I2C, ...).

- (protogen.esb.rcp.dev.enQuery.qryPins)=

  **`qryPins`** — [O] Retrieve a list of pins and supported functions.

- (protogen.esb.rcp.dev.enQuery.qryServerStatus)=

  **`qryServerStatus`** — [H] Get state of the server, whether fail-safe mode was activated or not.

- (protogen.esb.rcp.dev.enQuery.qryNetStatus)=

  **`qryNetStatus`** — [O] Get current network status.

- (protogen.esb.rcp.dev.enQuery.qryPtpStatus)=

  **`qryPtpStatus`** — [H] Get current PTP protocol status.

- (protogen.esb.rcp.dev.enQuery.qryPlcaStatus)=

  **`qryPlcaStatus`** — [H] Get current PLCA status.

- (protogen.esb.rcp.dev.enQuery.qrySchedulerStatus)=

  **`qrySchedulerStatus`** — [M] Get RCP Scheduler status.

- (protogen.esb.rcp.dev.enQuery.qryNvmStatus)=

  **`qryNvmStatus`** — [H] Get RCP NVM status.

- (protogen.esb.rcp.dev.enQuery.qryVendorStatus)=

  **`qryVendorStatus`** — [O] Get current vendor-specific status.

- (protogen.esb.rcp.dev.enQuery.qryClientStatus)=

  **`qryClientStatus`** — [M] Get current client status.
